# FNV Dialogs

Fallout: New Vegas-style dialogues for Garry's Mod.

Install: extract into `garrysmod/addons` or subscribe to the Steam Workshop item 3844042349.

A friendly citizen spawns automatically near the player. Press E to talk.
In dialogue: W/S select, E answer, ESC exit.
Optional console commands: fnv_menu, fnv_spawn, fnv_spawn_enemy, fnv_clear.
